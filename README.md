# odin-rock-paper-scissors

This repository host the first version of a console-based rock-paper-scissors game built for the Odin project curriculum

## How to play

Open the console to check the results of each round and simply enter your choice every time the prompt asks you to do so

## Take aways from confronting my solution to the one of other Odin project students 

- I might have  rely to heavily on if, else and else if 
- It could have been interesting to use more logical operators especially to simplify the way the winner of each game is determined
